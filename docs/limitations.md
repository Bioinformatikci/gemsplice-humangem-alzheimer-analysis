# Limitations

This repository is a curated portfolio artifact, not a complete computational environment snapshot.

## Scope Limits

- The repository does not include raw RNA-seq data.
- Large model binaries and `.mat` result files are excluded.
- Solver-specific experiments and local environment notes are excluded.
- The included results represent selected final outputs, not every exploratory run.

## Interpretation Limits

The included outputs should be interpreted as a compact summary of an Alzheimer/control model-analysis workflow. They are suitable for reviewing the analysis approach, code organization, selected figures, and final reporting, but they are not sufficient by themselves to fully reproduce every upstream computation.

## External Code

Original GEMsplice reference code is included under `external/original_gemsplice/` and remains separate from the project-specific analysis code. Its reuse is governed by the original GEMsplice license.
